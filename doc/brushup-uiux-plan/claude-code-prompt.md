# Chat App UI/UX 改善依頼

`packages/client` のチャットアプリ UI を、添付モック (`UI改善モック.html`) の方向性に合わせて全面リニューアルしてください。本ドキュメントは Claude Code 向けの実装依頼書です。

---

## 1. 背景・現状の課題

- サイドバーに機能（チャット / カレンダー / タスク / 保存ビュー / DM / ブックマーク / テンプレート / 管理画面 …）が **フラットに雑多に並んでおり、情報が散乱** している。
- 機能数の割に **視覚的な"重み"・階層感が弱く**、リッチな機能の存在に気づきにくい。
- メッセージ表示はバブル + 影で重く、コードブロックや引用との視覚的差分が出しづらい。
- 検索・保存ビューがサイドバー側にある一方、フィルタ UI が貧弱。
- カラーパレットは寒色系を志向しているが、オフセットされたトークン体系になっておらず、ダークモードのコントラストにムラがある。

---

## 2. 改善の方向性（モックで採用したもの）

### 2.1 サイドバーを 2 層構造へ再編
- **左 64px のアイコンレール**：ホーム(受信箱) / チャット / DM / 検索 / カレンダー / タスク / ファイル / ブックマーク / テンプレート / 管理 を縦並び。
- **右 280px のリスト列**：選択中のレールに応じて中身が切り替わる（チャット時はチャンネル + DM ツリー、検索時は保存ビュー一覧 …）。
- 「テンプレート管理」「管理画面」「保存ビュー」など **管理系・低頻度メニューはサイドバートップから外す**（レールの最下部やコマンドパレット ⌘K へ）。
- リスト列内のチャンネルは **カテゴリ（折り畳み）** + **ピン留めセクション** + **DM** の 3 段構成。

### 2.2 ホームを **Focus inbox** に作り変え（新規）
- 既存の `/` ランディングを刷新し、「受信箱」画面を新設：
  - サマリーカード 3 連（未読 / 予定 / タスク）
  - タブ：メンション / スレッド / リマインダー / 下書き / すべて
  - メンション・スレッド返信・リマインダーをタイムラインカード形式で並べ、行内に **返信** / **完了（既読化）** のクイックアクション
- ルーティングも `/` → 受信箱に変更し、現状の "とりあえず最後に開いたチャンネル" 起動を廃止。

### 2.3 チャンネル右側の **Context rail**（新規）
- メッセージエリアの右に **折り畳み可能な 320px ペイン**を追加。タブ：概要 / ピン留め / ファイル / 予定 / メンバー。
- トップバーの右端アイコン（モックの `panelR` アイコン）でトグル。状態は `localStorage` に永続化。
- モバイルではボトムシートにフォールバック。

### 2.4 メッセージは「バブルなし」の静かな表示
- 現状の `MessageBubble` の角丸 + 影 + 背景色を撤去。**名前 + 時刻 + 本文 + リアクション + スレッドリンク**を縦に並べるだけのフラット表示へ。
- ホバーで行背景を薄くし、右上にアクションバー（リアクション / 返信 / スレッド / ブックマーク / その他）が浮上。
- 同じ送信者からの連投は **avatar/名前/時刻を省略** したコンパクト表示にまとめる（行頭ホバー時のみ時刻を表示）。
- リアクションは "ピル形状（22px、自分のリアクションはアクセント色枠）"。

### 2.5 検索 / 保存ビュー
- 検索画面を独立画面化（レール「検索」を ON）。チップ式フィルタ（`from:` `in:` `has:` `before:` `after:` `tag:`）。
- 保存ビューはサイドバーから外し、検索画面の上部にピル形式で並べる。「現在の条件を保存」を併設。

### 2.6 ビジュアルトークン全面刷新（クールブルー寄り）
- 既存の独自カラー定義を捨て、**`oklch` ベースのトークン**へ。
- `--accent: oklch(0.55 0.15 250)` を唯一のアクセント色として使用。
- ダーク：`--bg: oklch(0.18 0.012 250)` 系のスレート。彩度は最大 0.02 までに制限。
- フォント：`Inter Tight` + `Noto Sans JP` + `JetBrains Mono`（コード）。
- トークン定義は `UI改善モック.html` 内の `styles.css` を **そのまま持ち込んで OK**（`:root` と `[data-theme="dark"]` のブロック）。クラス名・命名規約も流用可。

## 3. ファイル別の具体的な変更指示

### 3.1 `packages/client/src/components/Layout/AppLayout.tsx`
- 既存の単層サイドバー + ヘッダー構成を **3 列グリッド** へ：
  ```
  [Rail 64px] [List 280px] [Main 1fr] (+ optional Context rail 320px)
  ```
- レール幅・リスト幅・Context rail 表示状態は `useState` + `localStorage` で管理。
- 既存のトップバー（`Chat App` ロゴ + 検索 + ユーザーメニュー）はレールに吸収（ロゴはレール最上部の四角ロゴ、検索はレールの検索アイコン、ユーザーメニューはリスト列フッター）。

### 3.2 新規 `packages/client/src/components/Layout/Rail.tsx`
- アイコンボタン縦並び。`aria-current` で選択状態を表現。
- 上部：ホーム / チャット / DM / 検索 / カレンダー / タスク / ファイル / ブックマーク
- 下部（区切り線後）：テンプレート / 管理画面（admin ロールのみ）
- 各ボタンは未読バッジを表示できる（メンション数・DM 未読数）。
- ルーターと連動（react-router の `NavLink` を使用）。

### 3.3 `packages/client/src/components/Channel/ChannelList.tsx` 周辺
- `ChannelCategorySection` をベースに「ピン留め」「カテゴリ別」「DM」の 3 ブロック構成を実装。
- 行は `list-row` クラス相当のコンパクト行（高さ 28px、左に `#` / 🔒 / ピン アイコン）。
- 未読は太字 + 右端バッジ、メンションは accent 色バッジ、その他未読は muted バッジ。
- 「保存ビュー」セクション（`SavedViewSection.tsx`）はここから **削除**（検索画面に移設）。
- 「ブックマーク」「テンプレート管理」「管理画面」のナビゲーション項目もここから削除（レールに移譲）。

### 3.4 新規 `packages/client/src/pages/InboxPage.tsx`（Focus inbox）
- ルート `/` をこのページに変更。
- 既存 API：`GET /api/messages?mention=me&unread=1` 相当 + `GET /api/threads/subscribed` + `GET /api/reminders` を組み合わせる（必要なら新エンドポイント追加可）。
- タブ切替時の URL は `?tab=mentions` などクエリで管理。
- サマリーカードの値（未読数 / 今日の予定 / 未完タスク）は既存ストアから集計。

### 3.5 `packages/client/src/components/Chat/MessageItem.tsx` / `MessageBubble.tsx`
- `MessageBubble` の角丸背景を撤去。**プレーンな縦組み**に書き換え。
- 連投マージ：直前メッセージと「同送信者・5 分以内」なら `continued` クラスを付与してアバター/名前を非表示。
- ホバー時アクションバーは右上 `position: absolute; top: -12px; right: 24px;` でフロート（モックと同じ）。

### 3.6 新規 `packages/client/src/components/Channel/ContextRail.tsx`
- タブ：概要 / ピン留め / ファイル / 予定 / メンバー。
- 既存の `ChannelTopicBar` `PinnedMessages` `ChannelMembersDialog` のロジックを集約・タブ化。
- 開閉状態は `localStorage["contextRail.open"]` に保存。

### 3.7 `packages/client/src/components/Chat/SearchResults.tsx` & `SearchFilterPanel.tsx`
- 検索ページを 1 画面化（モーダル → ページ）。
- 上部：チップ入力欄 + 「現在の条件を保存」ボタン。
- 中段：保存ビューのピル一覧（クリックで条件適用）。
- 下段：結果リスト（チャンネル / 時刻クラム + 名前 + スニペット + ハイライト）。

### 3.8 トークン / グローバルスタイル
- `packages/client/src/index.css`（または同等ファイル）を **モックの `styles.css` をベースに全置換**。
- ダークモードは `<html data-theme="dark">` で切替（既存 `ThemeContext` の出力を `data-theme` 属性に変える）。
- 既存の Tailwind クラスやインラインスタイルでハードコードされた色は **すべて CSS 変数経由**に置き換え。

## 4. 守ってほしい開発ルール（`AGENTS.md` / `CLAUDE.md` 準拠）

- フロントは React 19。**新規データフェッチには `use(promise)` + `<Suspense>`**。`useEffect` + `setState` のフェッチは使わない。
- `use()` に渡す Promise は `useState` / `useMemo` で安定化させる。
- 既存のテストは原則維持。**変更したコンポーネントはテスト追加 / 更新**。
- DB 変更が伴う場合は `db/schema.hcl` を編集 → `atlas schema apply --env local`。`initializeSchema` は触らない。
- PR は `.github/PULL_REQUEST_TEMPLATE.md` の全セクションを埋める。
